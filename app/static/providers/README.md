# Provider marks

SVG paths from [Lobe Icons](https://github.com/lobehub/lobe-icons),
`packages/static-svg/icons/{deepseek,zai,zhipu,minimax,openai}.svg` (MIT; see LICENSE.txt).
GLM models use the Z.ai brand mark; the older Zhipu asset is retained for compatibility.
Only wrapper attributes and monochrome fills have been adapted for the dark UI.
Brand marks belong to their respective owners; their use identifies the model
provider and does not imply endorsement or affiliation.
